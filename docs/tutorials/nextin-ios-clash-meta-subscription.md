# Nextin iOS 使用指南：在 iPhone 与 iPad 导入 Clash Meta 订阅

## 一句话结论

在 iPhone 或 iPad 上安装 Nextin 后，复制云小狐用户中心提供的 `clash_meta` 订阅链接，或使用订阅二维码导入配置，再选择规则模式、节点并允许系统添加 VPN 配置，即可完成连接；订阅续费或内容变化后，可以在客户端内手动更新原有配置。

## 适用场景

本文适合以下情况：

- 第一次在 iPhone 或 iPad 上安装和使用 Nextin；
- 已经拥有云小狐订阅，但不清楚应选择哪种订阅格式；
- 想从其他客户端切换到基于 Clash Meta 内核的 iOS 客户端；
- 需要通过订阅链接或二维码导入配置；
- 订阅续费后，需要更新客户端中的配置；
- 配置导入成功，但连接、网页访问或 VPN 权限出现问题。

Nextin 的 App Store 页面显示，开发者为 `NEXTIN INC`，应用支持 iPhone 和 iPad，兼容要求为 iOS 15.0 或更高版本；页面同时说明该应用由 Clash Meta 内核驱动。实际可用版本、系统要求和界面名称应以设备当前 App Store 页面为准。

## 一、安装 Nextin

### 1. 检查 App Store 地区

打开 App Store 搜索 `Nextin`，先确认搜索结果中的开发者为 `NEXTIN INC`。云小狐官网说明中提到，Nextin 未在中国大陆 App Store 上架。如果在当前商店搜索不到，可能需要使用能够下载该应用的其他地区 Apple ID。

切换 Apple ID 地区前，应自行确认账户余额、现有订阅、付款方式和家庭共享等事项是否会受到影响。Apple 账户地区切换涉及账户设置，建议按照 Apple 当前页面的提示操作。

### 2. 从 App Store 下载

可以直接打开以下官方页面：

- [Nextin App Store 官方页面](https://apps.apple.com/us/app/nextin/id6754002454)

安装前核对以下信息：

- 应用名称为 `Nextin`；
- 开发者为 `NEXTIN INC`；
- 设备满足 App Store 当前显示的系统要求；
- 应用需要创建或使用 VPN 配置时，能够接受 iOS 的系统授权提示。

不要通过来源不明的安装包或修改版应用安装客户端。第三方应用的版本和按钮名称可能变化，遇到界面与本文不一致时，以当前应用实际显示为准。

## 二、复制云小狐订阅链接

1. 在 iPhone、iPad 或电脑浏览器中打开云小狐用户中心并登录。
2. 进入「我的订阅」或订阅管理页面。
3. 打开对应订阅的详情。
4. 在订阅格式中选择 `clash_meta`。
5. 点击复制按钮，获得完整订阅链接。

订阅链接通常是一段较长的 HTTPS 地址。复制后不要在链接中间加入空格、换行或其他字符，也不要把两个不同格式的链接拼接在一起。如果使用电脑打开订阅详情页，也可以让 iPhone 或 iPad 扫描页面中的订阅二维码。

订阅链接属于个人配置凭证，不应发布到公开代码仓库、论坛、群聊或截图中。如果链接已经泄露，应根据服务提供方用户中心提供的功能重置或更换订阅地址。

## 三、在 Nextin 中导入配置

Nextin 的具体界面可能随版本更新而变化，但常见导入流程包括粘贴订阅链接和扫描二维码两种方式。

### 方式 A：粘贴订阅链接

1. 打开 Nextin，进入首页或配置添加页面。
2. 将复制的订阅链接粘贴到输入框。
3. 点击「下一步」、提交或类似的确认按钮。
4. 等待客户端下载并解析配置。
5. 导入完成后，检查配置名称、节点列表和配置状态。

第一次导入时，建议优先使用云小狐用户中心提供的 `clash_meta` 格式。导入过程中不要连续重复点击提交，也不要同时切换多个 VPN 客户端，以免下载被中断或出现配置冲突。

### 方式 B：扫描订阅二维码

1. 在电脑浏览器中打开云小狐用户中心的订阅详情页。
2. 在 Nextin 的配置添加页面点击扫码按钮。
3. 使用 iPhone 或 iPad 扫描订阅详情页中的二维码。
4. 检查客户端识别出的订阅地址或配置名称。
5. 点击下一步并等待配置下载完成。

如果扫码无法完成，可以改用粘贴链接方式。二维码显示不完整、屏幕亮度不足、扫码距离不合适或页面缩放过大，都可能影响识别；此时应重新显示完整二维码，或直接复制原始订阅链接。

### 导入失败时的备用尝试

如果使用 `clash_meta` 格式导入失败，可以回到云小狐用户中心，按照页面实际提供的选项尝试 `singbox` 格式，再重新复制完整链接并导入。不同格式对应不同配置结构，不能把一个格式的内容手动改写成另一个格式。

如果两种格式都无法导入，优先检查：

- 订阅链接是否完整并以 `https://`/ 开头；
- 浏览器复制时是否遗漏了开头或结尾字符；
- 当前网络是否能够打开订阅地址；
- 设备上是否同时运行了其他 VPN 或代理应用；
- Nextin 是否为 App Store 中的正版应用。

## 四、选择代理模式并连接

### 1. 选择规则模式或全局模式

配置导入后，回到 Nextin 首页，找到「代理模式」或相近名称的设置。

- **规则模式**：根据配置中的规则决定哪些流量通过代理、哪些流量直连，适合日常使用和混合访问场景。
- **全局模式**：让更多流量统一通过当前代理，适合临时排查规则是否导致某个网站或应用无法访问。

如果只有某个网站打不开，可以先在规则模式下检查，再临时切换全局模式进行对比。全局模式并不等于一定能够访问所有服务，实际结果还会受到节点、目标服务限制、设备网络和客户端配置等因素影响。

### 2. 选择节点

进入节点列表后，选择一个可用节点。节点名称可能包含地区、编号或线路标识。同一地区可能有多个节点，可以根据连接是否稳定、常用网站是否能够正常打开等实际表现进行选择。

不要仅依据一次延迟数值判断节点是否适合长期使用。测试时应结合目标应用、当前网络环境和实际连接情况；如果某个节点无法连接，可以切换其他节点后再次尝试。

### 3. 开启连接开关

1. 返回 Nextin 首页。
2. 点击页面上的总开关或连接按钮。
3. 第一次连接时，iOS 可能弹出添加 VPN 配置的系统提示。
4. 点击「允许」，并按照系统提示验证设备密码或身份。
5. 返回 Nextin，确认客户端显示已连接。

Apple 的 iPhone 使用说明中提供了 VPN 与设备管理相关设置入口。若设备存在配置描述文件，可以在「设置」→「通用」→「VPN 与设备管理」中查看相关项目；学校、企业或其他组织管理的设备，可能会限制 VPN 配置权限。

看到系统状态栏显示 VPN 标识后，再打开浏览器或目标应用进行测试。使用完毕后，在 Nextin 中关闭总开关即可断开连接。

## 五、更新已有订阅

当订阅续费、节点列表或配置内容发生变化时，通常不需要删除客户端，也不需要重新安装 Nextin。可以尝试更新已经导入的配置：

1. 打开 Nextin，进入底部的「个人中心」或配置管理页面。
2. 找到「服务配置」或已经导入的云小狐配置。
3. 在对应配置上向左滑动，或打开该配置的更多操作菜单。
4. 点击「更新」或相近名称的按钮。
5. 等待更新完成，再检查配置状态、节点列表和到期信息。

如果更新后仍显示旧内容，应确认更新的是正确配置，而不是设备中保留的旧订阅。可以删除重复配置、切换一次 Wi-Fi 与移动数据，或在网络稳定后重新执行更新。

## 常见问题

### 1. App Store 搜不到 Nextin，怎么办？

先确认当前 Apple ID 所属地区，并检查搜索结果中的开发者是否为 `NEXTIN INC`。如果当前地区没有提供该应用，需要使用能够下载该应用的其他地区 Apple ID。切换账户前，请自行确认账户余额、订阅、付款方式和家庭共享等设置的影响。

### 2. 粘贴订阅链接后提示导入失败，怎么办？

按照以下顺序检查：

1. 确认链接完整，并且以 `https://`/ 开头；
2. 从云小狐用户中心重新复制，不要使用可能被截断的聊天消息；
3. 确认选择的是 `clash_meta`，不要把不同格式的内容混用；
4. 切换 Wi-Fi 和移动数据，排除当前网络暂时无法访问订阅地址；
5. 关闭其他 VPN 或代理客户端，避免多个应用同时接管网络；
6. 确认 Nextin 已更新到 App Store 当前可用版本。

### 3. 显示已连接，但网页打不开，怎么办？

先检查当前节点是否可用，再确认代理模式。可以临时从规则模式切换为全局模式进行对比：

- 如果全局模式可以访问，而规则模式不行，问题可能与规则匹配或目标域名处理有关；
- 如果两种模式都无法访问，可以切换节点，并检查设备网络和 VPN 权限；
- 如果只有一个应用异常，应同时检查该应用自身的网络设置和登录状态。

还应进入「设置」→「通用」→「VPN 与设备管理」，查看是否存在其他 VPN 配置或组织管理策略。不要让多个 VPN 客户端同时运行。

### 4. 第一次连接没有出现「允许」按钮，怎么办？

回到 Nextin 首页再次点击连接开关。如果系统曾经拒绝过 VPN 配置请求，可以在系统设置中查看现有 VPN 配置，删除不再使用或重复的配置后再尝试。若设备由学校、企业或其他组织管理，管理员策略可能限制添加 VPN 配置，此时需要联系设备管理员。

### 5. 续费后为什么仍显示旧的到期时间或节点？

客户端可能仍在使用旧配置。进入 Nextin 的配置管理页面，找到对应的云小狐配置并执行更新。更新前确认当前配置使用的是正确订阅地址；如果更新失败，可以切换网络后重试，并清理设备中重复的旧配置。

### 6. Nextin 和其他 iOS 客户端应该如何选择？

选择客户端时，可以比较系统兼容性、订阅格式支持、配置更新方式、权限流程和自己对界面的熟悉程度。Nextin 的 App Store 页面说明其由 Clash Meta 内核驱动；其他客户端的功能、购买方式和配置格式应以各自官方页面为准。不要仅根据应用名称或第三方截图判断兼容性。

使用网络代理、VPN 或相关客户端时，请遵守当地法律法规以及所使用网络服务的条款。
