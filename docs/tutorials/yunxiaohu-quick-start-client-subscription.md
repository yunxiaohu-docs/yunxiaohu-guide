# 新手快速开始云小狐：套餐、客户端与订阅导入

## 一句话结论

使用云小狐通常可以按“选择套餐并付款 → 安装适合设备的客户端 → 导入订阅并开启连接”完成；如果使用云小狐官方客户端，登录账号后订阅会自动配置，通常可以省略手动复制订阅链接的步骤。

## 适用场景

本文适合第一次使用云小狐、刚更换电脑或手机、不了解订阅链接用途，或者安装客户端后不知道下一步如何连接的用户。内容覆盖 Windows、macOS、Android、iPhone 和 iPad，并区分官方客户端与第三方客户端的操作路径。

如果你已经安装了客户端，但遇到连接失败、订阅更新失败、节点列表为空或应用无法访问等问题，可以先按本文确认“账号、客户端、订阅、连接开关”四个环节是否都已完成，再进入具体的连接排查文档。使用网络服务时，请遵守当地法律法规。

## 第一步：选择套餐并完成付款

打开云小狐套餐页，根据预计的每月流量需求选择套餐。云小狐官网当前说明的流量档位包括：

| 流量档位 | 适合的基本情况 |
| --- | --- |
| 50GB | 日常网页、文字资料和少量图片访问 |
| 100GB | 经常使用网页、图片和开发工具 |
| 200GB | 多设备使用，或需要较多视频、文件和 AI 工具访问 |
| 500GB | 流量需求较高，或多个设备长期使用 |

以上档位和计费方式来自云小狐官网说明，具体可选项以套餐页显示为准。付款周期可以选择月付、半年付或年付；半年付、年付需要一次付清，但流量仍然按月重置。付款成功后，系统会自动开通，一般不需要等待人工审核。

### 如何估算需要多少流量

可以先按“设备数量 × 每月使用天数 × 每天使用时长”估算，再结合实际用途预留余量。文字网页、代码仓库和普通接口请求通常比高清视频或大文件下载消耗更少；如果需要在电脑、手机和平板上同时使用，应把所有设备的使用量合并考虑。

这里不建议仅根据套餐名称判断是否够用，也不要把“流量按月重置”理解为半年或年付后一次性获得全部周期流量。最终应以用户中心显示的剩余流量、重置日期和套餐规则为准。

## 第二步：按设备安装客户端

安装客户端时，优先从项目官方仓库、官方商店或云小狐官网提供的下载入口获取安装包。不要从搜索结果中的不明下载站安装网络代理客户端，也不要把账号密码或订阅链接交给来历不明的网页。

| 设备 | 推荐选择 | 说明 |
| --- | --- | --- |
| Windows 电脑 | 云小狐官方客户端或 Clash Verge Rev | 官方客户端适合新手；Clash Verge Rev 适合已经熟悉 Clash 配置的用户 |
| Mac 电脑 | 云小狐官方客户端或 Clash Verge Rev | Apple 芯片与 Intel 芯片需要选择对应安装包 |
| Android 手机 / 平板 | 云小狐官方客户端或 Clash Meta for Android | 首次启动时通常需要允许应用创建 VPN 连接 |
| iPhone / iPad | Shadowrocket 或 Nextin | 当前没有云小狐官方 iOS 客户端，需要使用第三方客户端 |

Clash Verge Rev 是一个基于 Tauri、面向 Windows、macOS 和 Linux 的图形客户端，项目代码和发布信息可在其官方 GitHub 仓库查看。([github.com](https://github.com/clash-verge-rev/clash-verge-rev)) Clash Meta for Android 的官方仓库位于 MetaCubeX 组织下，仓库说明其定位是 Android 上的规则型隧道客户端。([github.com](https://github.com/MetaCubeX/ClashMetaForAndroid)) 如果你使用 sing-box 生态中的客户端，应以 sing-box 官方项目文档和客户端自身说明为准。([github.com](https://github.com/SagerNet/sing-box))

### Windows 与 macOS

1. 根据系统下载对应客户端并完成安装。
2. macOS 用户先确认自己的设备是 Apple 芯片还是 Intel 芯片：打开“关于本机”即可查看。
3. Windows 用户安装完成后，首次运行时根据系统提示允许应用联网；部分需要系统代理或 TUN 权限的功能可能还需要管理员授权。
4. 如果使用 Clash Verge Rev，可从其官方 GitHub 仓库进入 Releases 页面下载对应版本，不要把仓库源码压缩包误当成普通安装包。

### Android

1. 安装云小狐官方客户端或 Clash Meta for Android。
2. 首次导入或连接时，允许应用创建 VPN 连接。
3. 如果系统启用了省电限制，建议检查该客户端是否被系统限制后台运行；不同手机厂商的设置名称可能不同。
4. 不需要同时打开多个 VPN 类客户端，否则它们可能争抢系统 VPN 权限。

### iPhone 与 iPad

iPhone / iPad 目前没有云小狐官方客户端。使用 Shadowrocket 或 Nextin 时，需要先通过非中国大陆地区的 Apple ID 获取对应应用，具体下载方式以应用商店和云小狐相关教程为准。安装第三方客户端后，再按下一步导入订阅。

## 第三步：导入订阅链接

如果使用云小狐官方客户端，登录后订阅通常会自动配置，可以跳过手动导入。以下步骤适用于 Clash Verge Rev、Clash Meta for Android、Nextin、Shadowrocket 以及 sing-box 系客户端。

### 1. 从用户中心复制订阅

1. 登录云小狐用户中心。
2. 进入“我的订阅”。
3. 点击“查看详情”，打开订阅详情页。
4. 在“订阅链接”区域按照客户端选择对应格式。
5. 点击“复制”；如果是在手机上操作，也可以使用页面提供的“一键导入到 App”功能。

订阅格式按官网说明对应如下：

| 客户端 | 应选择的订阅格式 |
| --- | --- |
| Clash Verge Rev | `clash_meta` |
| Clash Meta for Android | `clash_meta` |
| Nextin | `clash_meta` |
| Shadowrocket | `v2rayn` |
| sing-box 系客户端 | `singbox` |

订阅链接相当于客户端获取配置和节点列表的入口，应像密码一样保管。不要把完整链接公开发布到论坛、群聊、工单截图或代码仓库中；如果怀疑链接泄露，应在用户中心查看是否可以重置或重新生成订阅。

### 2. 在客户端中添加订阅

不同客户端的按钮名称可能略有差异，但通常都在“配置”“订阅”“Profiles”或“订阅管理”页面完成：

1. 打开客户端的配置或订阅管理页面。
2. 选择“添加订阅”“从 URL 导入”或类似选项。
3. 粘贴刚才复制的订阅链接。
4. 保存并等待客户端拉取配置。
5. 在配置列表中选中刚导入的配置。
6. 进入节点列表，选择一个可用节点。
7. 打开客户端的连接开关，并按系统提示允许建立 VPN 或系统代理。

如果导入后看不到节点，先不要反复点击导入。应检查链接是否完整、订阅格式是否与客户端匹配、账号是否已开通，以及客户端是否能正常访问订阅地址。

### 3. 选择节点并开启连接

节点列表出现后，可以先选择延迟数字相对较低、名称容易识别的节点进行连接。延迟数字主要反映客户端到目标节点的往返时间，不等于所有网站或应用的实际下载速度；如果需要了解规则、全局和直连的区别，可继续阅读平台内的代理模式说明。

连接开关打开后，先访问一个普通网页或打开需要网络连接的应用进行验证。不要只看客户端界面显示“已连接”就认定所有流量都已经按照预期转发，还要确认系统代理状态、客户端模式以及目标应用是否使用了系统网络设置。

## 连接完成后的基本设置

### 规则模式、全局模式与直连

- **规则模式**：根据配置中的域名、IP 或规则集决定哪些请求走代理，哪些请求直连，适合日常使用。
- **全局模式**：尽量让客户端支持的请求统一经过当前选择的节点，适合排查规则是否导致某个站点无法访问，但不一定适合长期使用。
- **直连模式**：不使用代理连接，适合临时关闭代理或对比连接结果。

如果只是第一次验证订阅是否生效，可以先使用规则模式；如果怀疑某条规则匹配错误，再临时切换到全局模式对比。排查完成后，建议恢复到符合自己需求的模式。

### 订阅更新

订阅不是一次导入后永久不变的文件。节点、规则或配置发生变化时，需要在客户端的订阅管理页面执行“更新”“刷新”或“更新全部”。更新前确认网络正常，更新后重新选择目标配置和节点。

如果客户端支持定时更新，可以设置合理的更新周期；如果客户端没有成功拉取，不要直接删除当前仍可用的旧配置，以免失去临时可用的回退方案。

## 常见问题

### 1. 官方客户端和第三方客户端应该怎么选？

第一次使用，优先选择云小狐官方客户端。它的流程通常是安装后登录账号，订阅自动配置，少一个手动复制和选择格式的步骤。已经熟悉 Clash 或 sing-box 配置管理的用户，可以根据自己的系统和使用习惯选择第三方客户端。

### 2. 订阅链接复制后，客户端提示格式错误怎么办？

先确认选择的订阅格式是否对应当前客户端：Clash Verge Rev、Clash Meta for Android 和 Nextin 使用 `clash_meta`，Shadowrocket 使用 `v2rayn`，sing-box 系客户端使用 `singbox`。然后检查链接是否被聊天软件截断、是否多复制了空格或换行，并确认账号套餐已经成功开通。

### 3. 导入成功但节点列表为空怎么办？

依次检查四点：一是当前配置是否已经被选中；二是订阅是否已经更新完成；三是客户端是否能访问订阅地址；四是用户中心中的订阅是否仍在有效期内。如果仍然为空，可以重新复制订阅链接后再次导入，但不要在未确认原因前删除唯一的旧配置。

### 4. 客户端显示已连接，但网页仍然打不开怎么办？

先确认系统代理或 VPN 权限是否已允许，再检查客户端是否处于直连模式、是否选择了正确配置，以及浏览器是否单独设置了代理。也可以临时切换节点或模式进行对比。若只有某个应用无法访问，检查该应用是否使用独立代理设置、是否被防火墙拦截，或是否需要重新启动应用。

### 5. 手机提示无法创建 VPN 连接怎么办？

确认系统没有同时运行另一个 VPN、网络权限没有被系统限制，并关闭可能占用 VPN 权限的安全软件或其他代理工具后重试。Android 设备还应检查省电策略和后台限制；iPhone / iPad 则应按照系统弹窗允许客户端添加 VPN 配置。

### 6. 订阅链接泄露了怎么办？

订阅链接通常包含获取配置的授权信息，不应公开分享。立即进入用户中心查看是否支持重置、重新生成或修改订阅；完成处理后，在客户端删除旧订阅并导入新的链接。若无法自行处理，可通过云小狐用户中心提交工单咨询。
