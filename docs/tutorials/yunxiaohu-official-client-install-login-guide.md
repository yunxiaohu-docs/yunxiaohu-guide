# 云小狐官方客户端安装与登录教程：Windows、macOS、Android 一键连接

## 一句话结论

如果你希望少处理订阅链接和客户端配置，可以直接从云小狐下载对应系统的官方客户端，安装后使用网站账号登录；登录成功后，客户端会自动获取账号下的订阅配置，通常不需要手动复制订阅链接。

## 适用场景

本文适合以下用户：

- 第一次在 Windows 10/11、macOS 或 Android 上安装云小狐客户端；
- 不清楚 Apple 芯片 Mac 和 Intel Mac 应该下载哪个安装包；
- macOS 首次打开时遇到“无法验证开发者”“已损坏”等提示；
- Android 安装后没有看到 VPN 授权提示，或连接后网页无法打开；
- 已经登录客户端，但不知道如何连接、切换线路、查看流量和断开连接；
- 想在官方客户端与 Clash Verge Rev 等第三方客户端之间选择更简单的使用方式。

官方客户端与第三方客户端的主要使用差异，是官方客户端直接使用云小狐账号登录并自动获取订阅，而第三方客户端通常需要用户手动导入订阅链接。需要使用规则、全局、直连、TUN 或分应用代理等高级功能时，可以先关闭官方客户端中的“简洁模式”，再查看完整功能入口。

## 一、下载安装包

### Windows 10 / 11

打开云小狐下载页面，在“官方客户端”区域选择 Windows 版本。根据官网说明，Windows 10/11 使用 64 位安装包，下载完成后双击安装文件，按向导提示完成安装即可。

如果 Windows 弹出蓝色的“Windows 已保护你的电脑”提示，不要直接关闭安全提示。先确认安装包来自可信的云小狐下载页面，再根据系统界面选择“更多信息”，之后决定是否继续运行。Windows 的 SmartScreen 会根据文件、网站和发布者的信誉对下载内容进行评估；微软建议从可信来源下载软件，并保持 Windows 与安全组件更新。([support.microsoft.com](https://support.microsoft.com/en-us/windows/security/windows-security/app-browser-control-in-the-windows-security-app))

### macOS

macOS 需要区分 Apple 芯片与 Intel 芯片：

- M1、M2、M3、M4 等 Apple 芯片设备，选择 Apple 芯片版本；
- 较早的 Intel Mac，选择 Intel 版本。

打开 DMG 文件后，将云小狐图标拖入“应用程序”文件夹。云小狐官网原说明中的 macOS 示例使用的是 Apple 芯片安装包，Intel 版本的安装流程相同，但安装包架构不同。

Apple 的“门禁”机制会检查来自互联网的 App 的签名、公证状态和来源。对于尚未公证或无法验证开发者的 App，Apple 建议用户先确认软件来自可信来源且未被篡改，再在“系统设置 → 隐私与安全性”中查看“仍要打开”选项。若系统提示 App 已损坏、包含恶意软件或已被撤销授权，不应简单绕过安全提示，应重新从可信来源下载并核对文件。([support.apple.com](https://support.apple.com/zh-cn/102445))

如果按照云小狐官网说明安装后，仍然出现“无法验证开发者”或“已损坏”提示，可以在确认安装包来源可靠的前提下，打开“终端”执行：

```bash
xattr -cr /Applications/YunXiaoHu.app
```

命令执行后没有输出通常表示命令已完成。然后重新打开“应用程序”中的云小狐。该命令只针对路径为 `/Applications/YunXiaoHu.app` 的应用；如果你把 App 放在其他目录，需要先将它移动到“应用程序”，或根据实际路径调整命令。

### Android

Android 用户从云小狐下载页面选择 Android 安装包。官网说明建议优先使用 64 位版本，只有遇到“解析包出错”等兼容性提示时，再考虑使用 32 位版本。

如果系统提示“禁止安装未知来源应用”，按照 Android 当前界面进入浏览器或文件管理器的安装权限设置，允许当前来源继续安装。不同手机品牌的菜单名称可能不同，可以在系统设置中搜索“安装未知应用”或“未知来源”。Android 官方文档说明，VPN 应用可以通过应用自身完成配置和连接；系统设置中的 VPN 页面也可以查看已经添加的 VPN，并在连接后显示 VPN 状态。([support.google.com](https://support.google.com/android/answer/9089766?hl=en-ca))

## 二、首次打开与登录

### 1. 同意免责声明

部分平台第一次启动时会先显示免责声明。需要将页面滑到内容底部，“同意”按钮才会变为可点击状态。完成确认后进入登录页，后续启动一般不会重复显示。

### 2. 使用云小狐账号登录

在登录页填写云小狐网站使用的账号邮箱和密码，然后点击“登录”。如果还没有账号，可以点击“注册账号”，完成注册和套餐购买后再返回客户端登录。

官方客户端会使用账号信息自动获取对应订阅配置，因此不需要像 Clash Verge Rev、Clash Meta 等第三方客户端那样，先复制订阅链接再手动粘贴。换电脑、换手机或重装系统后，只要使用同一个账号重新登录，客户端就会再次获取账号下的配置。

如果你选择使用第三方工具，请只从其官方仓库或官方文档获取安装包。例如，Clash Verge Rev 的官方仓库说明其支持 Windows、macOS 和 Linux，并提供 Stable、AutoBuild 等不同发行渠道；日常使用应优先确认下载的是官方仓库发布的版本。([github.com](https://github.com/Clash-Verge-rev/clash-verge-rev))

## 三、一键连接与断开

登录成功后进入首页，通常可以看到以下信息：

- 中间的连接按钮；
- 当前线路或自动选择状态；
- 套餐、剩余流量、已用流量和到期日期；
- 连接后的持续时间和实时上下行状态。

点击首页中间的大按钮开始连接。连接成功后，按钮会变为绿色并显示“已连接”。Windows 可能会弹出管理员权限确认，用于安装或启用本地系统服务；macOS 默认可以直接连接，如果在高级功能中启用虚拟网卡或 TUN，首次可能需要输入系统密码；Android 会弹出系统的“VPN 连接请求”，确认后状态栏通常会出现钥匙或 VPN 图标。

Android 官方说明中，连接状态可以在“设置 → 网络和互联网 → VPN”中查看；不同厂商的菜单名称可能略有差异，也可以直接在系统设置中搜索“VPN”。([support.google.com](https://support.google.com/android/answer/9089766?hl=en-ca))

不再使用时，再次点击连接按钮即可断开。按钮恢复为“点击连接”后，设备回到未连接状态；Android 状态栏中的 VPN 或钥匙图标也会消失。

## 四、切换线路与查看延迟

如果不想使用“自动”线路，可以点击首页“当前线路”旁边的“更换”，进入线路列表，再点击右上角的“测速”。列表会显示线路的延迟数值，选择合适的线路后点击对应条目，客户端会返回首页并更新当前线路。

延迟表示数据往返所需的时间，受设备位置、网络运营商、线路距离、当时网络状况等因素影响。低延迟不等于所有场景都更适合：日常网页和视频通常可以优先尝试延迟较低的线路；某些服务如果要求特定地区，则应根据服务本身的地区要求选择对应线路。若同一地区有多个线路，一条不可用时可以换另一条；不想手动选择时，可以保留“自动”。

本文不对线路速度、在线率、解锁情况或节点数量作结论，实际连接结果应以你自己的设备、网络和客户端状态为准。

## 五、查看套餐、流量与高级设置

首页卡片通常显示当前套餐、剩余流量、已用流量和到期日期。卡片右上角的刷新按钮可以手动刷新状态；“续费 / 加流量”和“切换套餐”会打开网站上的对应页面。续费、加流量或更换套餐后，官方客户端一般会自动更新账号配置，不需要重新复制订阅链接。

客户端默认开启“简洁模式”，主要保留首页和设置。需要更多功能时，可以进入“设置”，关闭简洁模式，查看“代理”“配置”“实时连接”等入口。根据官网说明，完整功能可能包括规则、全局、直连、虚拟网卡 TUN 和分应用代理等选项。不了解具体选项时，建议先保留默认值，确认基础连接正常后再逐项调整。

## 常见问题

### 1. 提示“邮箱或密码错误”怎么办？

先使用同一组账号信息登录云小狐网站，确认邮箱和密码可以正常使用。如果网站也无法登录，优先在网站完成密码重置，再返回客户端登录。注意检查输入法、邮箱前后空格和密码大小写。

### 2. 登录成功但点击连接后仍然无法使用怎么办？

先进入“更换”线路列表，选择一个有延迟结果的线路重新连接；然后检查设备上是否同时开启了其他 VPN、代理软件或系统级网络工具。多个软件可能争用同一个本地端口或系统代理入口，排查时应先全部退出，只保留一个客户端运行。

如果仍然无法连接，可以依次确认：客户端是否为最新版本、系统是否弹出了权限确认、账号套餐是否有效、当前网络是否能正常打开云小狐网站，以及客户端日志中是否有明确错误信息。

### 3. macOS 提示“无法验证开发者”或“已损坏”怎么办？

先确认安装包来自云小狐官网，且没有通过不明镜像或改包渠道获取。Apple 建议在确认软件可信的情况下，打开“系统设置 → 隐私与安全性”，查找“仍要打开”选项。若页面没有该选项，可以先尝试正常打开一次，再返回设置页面查看。([support.apple.com](https://support.apple.com/zh-cn/102445))

如果仍按官网说明处理，可确认 App 已位于 `/Applications/YunXiaoHu.app`，然后执行：

```bash
xattr -cr /Applications/YunXiaoHu.app
```

如果系统明确提示 App 已损坏、包含恶意软件或来源异常，不建议无条件绕过，应删除后重新下载并检查来源。

### 4. Android 没有弹出 VPN 请求怎么办？

先回到客户端重新点击连接，再查看系统“设置 → 网络和互联网 → VPN”中是否存在云小狐或对应 VPN 项目。Android 官方文档指出，VPN 应用的连接流程可能由应用自身发起，系统设置中的菜单名称也会因设备厂商而不同。([support.google.com](https://support.google.com/android/answer/9089766?hl=en-ca))

如果客户端被系统省电策略限制，进入电池或应用管理设置，将云小狐设置为允许后台运行或不限制后台活动。不同品牌的名称可能是“自启动”“后台运行”“电池优化”“不受限制”等。修改后重新打开客户端并再次授权。

### 5. 退出登录会不会影响套餐和流量？

退出登录主要会移除本机上的账号会话和订阅配置，不等于注销网站账号。重新登录后，客户端会再次获取账号配置；套餐、流量和到期状态以账号本身为准。

### 6. 官方客户端和第三方客户端可以同时使用吗？

可以同时安装，但不建议同时启用。多个代理或 VPN 客户端可能同时修改系统代理、创建虚拟网卡或占用本地端口，导致连接异常。排查问题时，建议一次只运行一个客户端。

### 7. 如何更新客户端？

如果客户端出现新版本提示，可以按提示更新；也可以回到云小狐下载页面下载最新安装包并覆盖安装。更新前建议先断开连接并退出客户端。官网说明中，覆盖安装通常会保留登录状态和设置，但如果系统或客户端提示清除数据，应先确认是否需要备份自定义配置。
